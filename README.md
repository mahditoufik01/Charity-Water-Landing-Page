# charity: water Landing Page

Beginner friendly HTML and CSS implementation based on the Canva mockup.

## Files

- `index.html` contains the website structure and text.
- `styles.css` contains all colors, layout, responsive design, and hover effects.
- `img/` contains the logo and hero image.

## Run in GitHub Codespaces

1. Upload or copy these files into your Codespace repository.
2. Make sure `index.html` is in the repository root.
3. Open `index.html` with Live Preview if available, or run a simple local server.
4. Commit and push your changes.
5. In GitHub, open **Settings > Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select your main branch and `/ (root)`, then save.
8. Wait for GitHub Pages to publish the site and copy the URL that looks like:
   `https://username.github.io/repository-name`

## Beginner notes

The page uses only HTML and CSS. There is no JavaScript framework.
The CSS includes responsive media queries and simple transition and transform effects.
